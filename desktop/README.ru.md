# AshProxy для Windows x64

Раздел «Родительский прокси» позволяет направить трафик через HTTP CONNECT или SOCKS5. В разделе «Резервные копии» доступны последние 20 сохранённых конфигураций, включая параметры аутентификации.

Распакуйте ZIP целиком и откройте ashproxy.exe. Приложению требуется системный Microsoft Edge WebView2 Runtime. При необходимости установите [WebView2 с сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).

На вкладке **Обзор** нажмите **Запустить**. В браузере или другом клиенте выберите HTTP-прокси 127.0.0.1:3128 либо SOCKS5 127.0.0.1:1080. HTTPS работает через HTTP CONNECT. Настройки системного прокси Windows приложение не меняет.

На вкладке **Конфиг** можно поменять порты, локальный IPv4-адрес, подсети клиентов и ограничения скорости. В поле «Разрешённые подсети» перечисляются через запятую несколько сетей с любой маской, например `127.0.0.1/32, 192.168.90.0/23`; адрес без маски считается одним узлом, а `0.0.0.0/0` разрешает любые адреса. Для доступа из домашней сети укажите адрес сетевого адаптера и CIDR своей подсети. Для доступа по паролю раскройте «Аутентификация». Смена активной конфигурации прерывает текущие соединения. При ошибке запуска приложение пытается восстановить прежнюю конфигурацию. Пароль сохраняется как солёный проверочный хеш в формате 3proxy.

**Обзор** показывает трафик HTTP и SOCKS на пути к целевому серверу. RX — от сервера клиенту, TX — от клиента серверу. Текущая скорость вычисляется по разности счётчиков ядра. Исторический график показывает среднюю скорость на интервале. Минутные агрегаты хранятся в SQLite до 30 дней. **Клиенты** показывает активные входящие TCP-соединения, **Журнал** — до 200 последних строк текущего сеанса. Адреса URL и пароли в формат журнала не входят.

**Статистика** хранит суммарный трафик за всё время и таблицы по дням и месяцам. Счётчики пишутся в SQLite и переживают перезапуск программы; кнопка «Обнулить трафик» очищает накопленные значения, не останавливая прокси. Дни считаются по местному времени.

В **Настройках** отдельно включаются запуск программы при входе в Windows, открытие в трее и запуск ядра. Для работы в фоне используйте меню значка в трее. При выходе из приложения управляемое ядро завершает работу. Настройки и история находятся в %LOCALAPPDATA%\AshProxy.

Это сборка обычного пользовательского режима. Служба Windows, произвольные конфигурации 3proxy, управление отдельным соединением и полная матрица проверок Windows 10/11 ещё не готовы. Бинарники без Authenticode-подписи: издатель (AshSoft Ltd.) и версия указаны в свойствах файла.
